# algos-lab-4

## Сокращатель ссылок

## Описание

Сервис позволяет сохранять длинные ссылки и получать для них короткие коды. По короткому коду можно вернуть исходную ссылку. Пользователь может задать свой код или использовать автоматическую генерацию.

## Функциональность

- Добавление новой ссылки с возможностью указать свой короткий код
- Получение длинной ссылки по короткому коду
- Проверка существования короткого кода
- Вывод всех сокращённых ссылок с количеством переходов
- Определение самой популярной ссылки (по количеству переходов)

## Как работает

```
длинная ссылка: https://example.com/articles/python-basics
короткий код: python (или a1 при авто-генерации)
результат: python -> https://example.com/articles/python-basics
```

## Использование

Запустите программу:

```bash
python main.py
```

Появится меню с выбором действий:

```
============================================================
СОКРАЩАТЕЛЬ ССЫЛОК - ГЛАВНОЕ МЕНЮ
============================================================
1. Добавить новую ссылку
2. Найти длинную ссылку по коду
3. Проверить существование кода
4. Показать все ссылки
5. Показать самую популярную ссылку
6. Выход
============================================================
```

## Структура программы

- **Класс `LinkShortener`** — основная логика сервиса
  - `url_map` — словарь для хранения пар код-ссылка
  - `click_count` — словарь для подсчёта переходов
  - `add_link()` — добавление новой ссылки
  - `get_long_url()` — получение ссылки по коду
  - `link_exists()` — проверка существования кода
  - `get_all_links()` — вывод всех ссылок
  - `get_most_popular()` — поиск самой популярной ссылки (использует `map`)
