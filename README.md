# Сокращатель ссылок

## Описание

Сервис сохраняет длинные ссылки и выдаёт к ним короткие коды. По короткому коду можно получить исходную ссылку. Пользователь может задать свой код или использовать автоматическую генерацию.

## Функциональность

- Добавление ссылки со своим кодом или авто-генерацией
- Получение длинной ссылки по короткому коду
- Проверка существования кода
- Вывод всех ссылок с количеством переходов
- Поиск самой популярной ссылки через `map`

## Как работает

```
Ввод: https://example.com/python
Код: py (или a1 при авто-генерации)
Сохранено: py -> https://example.com/python
```

## Использование

```bash
python main.py
```

Меню программы:

```
1.Добавить 2.Найти 3.Проверить 4.Все 5.Популярная 6.Выход
>
```

### Примеры

**Добавление со своим кодом:**
```
> 1
Ссылка: https://python.org
Свой код? (да/нет): да
Код: py
Готово! Код: py
```

**Добавление с авто-кодом:**
```
> 1
Ссылка: https://github.com
Свой код? (да/нет): нет
Готово! Код: a1
```

**Поиск ссылки:**
```
> 2
Код: py
py -> https://python.org
```

**Проверка кода:**
```
> 3
Код: py
Да!
```

**Все ссылки:**
```
> 4
py -> https://python.org (3)
a1 -> https://github.com (1)
```

**Популярная ссылка:**
```
> 5
Популярная: py -> https://python.org (3)
```

## Структура

**Класс `LinkShortener`:**
- `links` — словарь код → ссылка
- `clicks` — словарь код → переходы
- `add(url, code)` — добавить ссылку
- `get(code)` — получить ссылку
- `exists(code)` — проверить код
- `show_all()` — показать все
- `popular()` — самая популярная (map)

**Функция `main()`** — меню и ввод с консоли.

## Особенности

- Проверка дубликатов ссылок и кодов
- Подсчёт переходов при каждом поиске
- Авто-коды: a1, a2, a3...
- Свой код для удобных имён (py, git, news)
- `map` + `max` для поиска популярной ссылки
